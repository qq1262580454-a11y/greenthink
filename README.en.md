## This is not a program. It is an idea.

AI now gives everyone the power to create.

But most creators are busy "building cars in the garage" — obsessed with parameters, debugging models, polishing prompts — while the complete, mature works they actually finish sit in local folders, never seen by a second pair of eyes.

**Greenthink is a showcase platform where AI-made creations get seen.**

- We do not show the creative process, only the final result
- We curate: complete, mature, final creative works — and the ideas and worldviews behind them
- We believe:

> **Ideas over parameters · Creativity over technique · Results over process · Imagination over tools**

## What it is

A place where anyone can submit, showcase, and discover AI-made creations:

| You can | How |
|---|---|
| 🎨 Submit your finished work | A piece, a plan, a tool — done in minutes |
| 👀 Discover others' creations | Browse the gallery, every work tells its story |
| 📖 Understand each work | Problem → Creative solution → Final result |
| ✅ Trust what you see | Every live work is reviewed and complete |

## Make the idea run

**For creators:** Open the site → "Submit Idea" → approved → your work is seen.

**For builders:** Code is only the vehicle; the idea needs people — creators submit works, designers polish visuals, developers send PRs, and sharers tell friends who are still "building cars in the garage."

## Technical appendix (for developers)

- **Stack**: Flask + vanilla HTML/CSS/JS, zero build, double-click to run
- **Run locally**: `pip install flask && python app.py` → http://127.0.0.1:5010
- **Data**: `data/results.json` — a public JSON anyone can verify
- **Images**: `static/img/works/<work-id>.jpg` (4:3, shown automatically when present)
- **Contributing**: [CONTRIBUTING.md](CONTRIBUTING.md) · look for `good first issue`
- **License**: [MIT](LICENSE)
